# Tasca 02 - Git, viatjant pel temps

## Descripció
En aquesta activitat hem treballat amb Git i GitHub per aprendre a gestionar l'historial de versions d'un repositori.

## Objectius
- Aprendre a crear commits correctament.
- Consultar l'historial de versions.
- Recuperar canvis amb git restore.
- Desfer commits amb git revert.
- Eliminar commits amb git reset.

## Eines utilitzades
- Git
- GitHub
- Visual Studio Code
- Git Graph
