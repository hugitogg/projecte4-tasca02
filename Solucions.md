# Solucions - Tasca 02

## Part 1. Bones pràctiques dels commits
Hem creat el fitxer README.md amb una descripció del repositori i hem fet el primer commit amb el tipus docs.

Després hem creat el fitxer 00-installer-config.yaml amb una configuració DHCP i hem fet un commit de tipus feat.

## Part 2. Historial del repositori
Hem utilitzat git log per consultar l'historial complet i git log --oneline per veure'n un resum.

També hem utilitzat Git Graph per visualitzar els commits i git show HEAD per consultar els últims canvis.

## Part 3. Recuperar versions anteriors
Hem modificat el fitxer de configuració per simular un error. Després hem utilitzat git status per comprovar els canvis i git restore per recuperar la versió anterior.

## Part 4. Recuperar commits anteriors
Hem creat diferents versions de la configuració de xarxa mitjançant commits.

Després hem utilitzat git revert per desfer els canvis dels commits posteriors i recuperar l'estat del segon commit.

També hem explorat un commit anterior amb Git Graph per observar les línies afegides i eliminades.

Finalment, hem utilitzat git reset --hard HEAD~1 per eliminar l'últim commit i comprovar l'estat final del repositori.

## Conclusions
En aquesta activitat hem après a gestionar l'historial de Git, consultar versions anteriors i recuperar o desfer canvis quan és necessari.
